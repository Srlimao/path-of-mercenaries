# items-paperdoll-inspector

Phase 4 `Items` tab vertical slice:
- `EquipmentPaperdoll`: 10-slot equipment layout with archetype weapon/off-hand validation indicators and quick starter gear loading.
- `PoeItemTooltip`: Authentic PoE tooltip displaying Stage 1 local weapon DPS (`pDPS`, `eDPS`, `APS`, `Crit`) and local defences.
- `PasteItemModal`: `Ctrl+V` clipboard interceptor and PoE `Ctrl+C` parser with sample presets and live tooltip preview.
- `ItemsTabView`: 3-column paperdoll, selected slot inspector, and 1-click Seed Uniques catalog.
