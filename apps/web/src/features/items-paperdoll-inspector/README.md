# items-paperdoll-inspector

Phase 4 & 5 `Items` tab vertical slice:
- `EquipmentPaperdoll`: 10-slot equipment layout with archetype weapon/off-hand validation indicators and quick starter gear loading.
- `PoeItemTooltip`: Authentic PoE tooltip displaying Stage 1 local weapon DPS (`pDPS`, `eDPS`, `APS`, `Crit`) and local defences.
- `PasteItemModal`: `Ctrl+V` clipboard interceptor and PoE `Ctrl+C` parser with sample presets and live tooltip preview.
- `UniquesBrowserPanel`: Searchable Uniques browser with slot filters, mod keyword search, `Merc Meta` toggle, and live `+DPS% / +EHP%` badges.
- `HoverDiffComparison`: Side-by-side Equipped vs Hovered Candidate PoE tooltips with DPS, EHP, Life, Max Hit, and Resistance deltas.
- `ItemRollAndTextEditor`: In-place roll sliders (`0%–100%`), Quality/Catalyst controls, and raw PoE text editor with live diff preview.
- `ItemsTabView`: 3-column paperdoll, inspector/what-if comparison, and Uniques browser workspace.
