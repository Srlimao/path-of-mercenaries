# `workspace-shell` Feature

Top-level desktop PoB workspace chrome:

- `TopActionHeader.tsx`: Build name, active archetype/level badges, reset & Phase 13 cloud/share/import controls.
- `WorkspaceTabBar.tsx`: Mode switcher (`Items` | `Skills` | `Config` | `Calcs`) with `F1`–`F4` hotkeys.
- `FeatureSlotPlaceholder.tsx`: Live component mount targets displaying engine state for each upcoming slice.
