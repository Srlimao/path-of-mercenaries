# `left-stat-sidebar` Feature

Persistent Path of Building left summary sidebar displaying:
- Mercenary Archetype & Level (1–85) selector with auto-derived Skill Level badge.
- Active Skill & Skill Part dropdowns.
- Offence metrics (`Combined Full DPS`, `Active Skill DPS`, Hit/Crit/Rate).
- Attributes, Pools (`Life`, `ES`, `Ward`, `EHP`), Resistances, and Per-Type Max Hit Taken.
